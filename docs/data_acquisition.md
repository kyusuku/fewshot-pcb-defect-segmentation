# Official Data Acquisition

Raw datasets, extracted archives, generated manifests, checkpoints, and outputs belong under `data/`, `weights/`, or `outputs/`, all of which are ignored by Git.

If your AutoDL SSH session cannot download from external URLs, use
[docs/autodl_data_setup.md](autodl_data_setup.md) instead: upload prepared data
or archives into the ignored `data/` folder, then run the same debug and
manifest scripts.

## Official Sources

### VisA

The official Spot-Diff repository describes VisA as 10,821 images across 12 object classes, including four PCB subsets (`pcb1`-`pcb4`). The repository also documents the AWS S3 download and the official `split_csv/1cls.csv` preparation flow.

AWS Open Data lists the VisA tar object as:

```text
s3://amazon-visual-anomaly/VisA_20220922.tar
```

This repo uses only the PCB categories.

### DeepPCB

The official DeepPCB repository contains `PCBData`. Its README describes 1,500 aligned template/test image pairs, 640 x 640 crops, six defect types, and box annotations in `x1,y1,x2,y2,type` format. It also states that 1,000 images are separated as train and the remaining images as test.

## Download Archives

```bash
python scripts/download_official_data.py --dataset all --output-dir data/raw --extract
```

This downloads:

- `data/raw/VisA_20220922.tar`
- `data/raw/DeepPCB-master.zip`

and extracts them under `data/raw/`.

If the VisA archive is already present, you can extract only:

```bash
python scripts/download_official_data.py --dataset visa --output-dir data/raw --extract
```

## Prepare VisA One-Class Layout

VisA's tar extracts category folders and `split_csv/` directly under `data/raw`.
The official one-class split is generated by Spot-Diff's helper script:

```bash
git clone --depth 1 https://github.com/amazon-science/spot-diff.git external/spot-diff
python external/spot-diff/utils/prepare_data.py \
  --split-type 1cls \
  --data-folder data/raw \
  --save-folder data/processed/VisA_pytorch \
  --split-file data/raw/split_csv/1cls.csv
```

The resulting root for this project's VisA loader is usually:

```text
data/processed/VisA_pytorch/1cls
```

## Create Train/Val/Test and Fold Manifests

After extracting DeepPCB and preparing VisA:

```bash
python scripts/create_manifests.py \
  --visa-root data/processed/VisA_pytorch/1cls \
  --deeppcb-root data/raw/DeepPCB-master/PCBData \
  --output-dir data/manifests \
  --val-ratio 0.2 \
  --seed 4880
```

The script writes:

- `data/manifests/visa_pcb_manifest.csv`
- `data/manifests/deeppcb_manifest.csv`
- `data/manifests/visa_pcb_folds.csv`
- `data/manifests/deeppcb_folds.csv`

The `*_manifest.csv` files provide one deterministic 80/20 development/validation split for quick smoke runs. The `*_folds.csv` files encode the Milestone 1 five-fold protocol with `fold_id` and `fold_split` columns. For VisA, fold validation is category-stratified within the official normal training images. For DeepPCB, the script uses `PCBData/trainval.txt` and `PCBData/test.txt` when they are present and balances validation folds using parsed box-instance defect class IDs. If those files are absent, it falls back to the documented 1,000 train / remaining test convention. Official test records stay locked as `fold_split=test` in every fold.

## Debug Real Samples

After manifest generation, save a few visual sanity checks:

```bash
python scripts/debug_dataset.py \
  --config configs/datasets/deeppcb.yaml \
  --root data/raw/DeepPCB-master/PCBData \
  --split test \
  --split-file data/raw/DeepPCB-master/PCBData/test.txt \
  --limit 8 \
  --output-dir outputs/debug_dataset/deeppcb_test
```

For VisA, run the same script after the Spot-Diff one-class layout is prepared:

```bash
python scripts/debug_dataset.py \
  --config configs/datasets/visa_pcb.yaml \
  --root data/processed/VisA_pytorch/1cls \
  --split test \
  --limit 8 \
  --output-dir outputs/debug_dataset/visa_pcb_test
```
